# QA — the dashboard reflows at 320 px and 200 % zoom (#84)

Packaged-build check of issue #84 on branch `fix/84-actions-overflow-narrow-width`, 2026-11-20.

## Setup

- `just smoke` build (`electron-vite build` + `electron-builder --linux dir`), launched twice
  (single-instance lock) under Xvfb with no `WAYLAND_DISPLAY`, temp `XDG_CONFIG_HOME`, CDP on a
  local port. `just smoke` green on the same build (13/13); red at 320 px before the fix.
- Real Docker stack: Penpot (8 containers, `on`), pinned with a `url` in a `Design` group, so its
  row carries the five actions. Read-only pass: no button was clicked.
- 200 % zoom: a 640 × 480 viewport with `zoom: 2` on the root element (CSS width 320 px).

## Checked (Chrome DevTools Protocol)

| Case | `scrollWidth` / `clientWidth` | Five actions inside the viewport |
|---|---|---|
| 320 × 568 | 305 / 305 | yes, two lines; `Open ↗` ends at 273 |
| 360 × 640 | 345 / 345 | yes, two lines; `Open ↗` ends at 313 |
| 640 × 480 at 200 % | 625 / 625 | yes, two lines; `Open ↗` ends at 561 |
